Practice

Functional testing first; now quality and release readiness from sprint to production.

I began with functional testing. Today I own quality and release readiness end to end.

In practice that means testing every sprint, running QA and production deployments through GitHub Actions, and debugging across Datadog logs, databases and Azure. When a live production issue appeared, I followed the logs back to its root cause.

Testing AI is its own discipline. Outputs shift from one run to the next, each run spends real money, and the cloud underneath behaves in complicated ways. So I validated Azure Service Bus auto-scaling, checked embedding indexing in Azure AI Search, and keep an eye on OpenAI and Claude usage while tests run.

I’ve built Playwright frameworks for smoke and regression testing with Allure reporting, tested multi-tenant setups, and work side by side with product managers and developers on requirements, bug analysis and workflow validation. I’m also growing my frontend skills by building and testing features on a new product.

Token spend gets reviewed next to test results. For an LLM feature, cost is a quality signal.
